# Definitions
- This directory contains definitions related to the Celeste Mods List project.
- Information regarding third-party libraries, tools, and other external systems is found in `docs/third-party/`.

## Purpose
The definitions in this directory help establish a common vocabulary and understanding for concepts specific to this project. They serve as a reference for developers/contributors to the CelesteMods platform.

## Structure
- Definitions are organized in markdown files.
- Each definition includes a clear, specific explanation of the term.
- Definitions may include additional context, examples, or references where appropriate.
- Subdirectories may be used to organize related definitions.

## Format
- Each file follows this structure:
  - `## Definitions` Section
    - Contains only subheadings.
	- Each subheading must contain 1 or more bullet points providing a definition.
